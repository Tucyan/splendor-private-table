# Splendor Implementation Plan

> **For agentic workers:** Use subagent-driven-development for the isolated rules engine; execute integration locally and review the finished implementation.

**Goal:** 私人使用的中文璀璨宝石基础版，支持房间、2–4 人对局、在线状态和无记忆 DeepSeek AI。

**Architecture:** Node.js 24 原生 HTTP + SSE，内存房间，服务器权威规则，纯 HTML/CSS/ES modules。使用浏览器 localStorage 保存昵称和不可猜测的会话令牌；服务端不公开令牌、牌堆顺序、他人的预留牌。

**Tech Stack:** Node.js built-ins, node:test, vanilla browser JavaScript, original SVG.

## Engine contract

Colors: `white, blue, green, red, black`; gold is wildcard. Card: `{id,level,bonus,points,cost}`. Noble: `{id,points,cost}`.
Player: `{id,name,ai,gems,bonuses,cards,reserved,nobles,score}`.
Game: `{players,bank,market:{1:[],2:[],3:[]},decks:{1:[],2:[],3:[]},nobles,turn,round,status:'playing'|'finished',finalRound,winners,log,pending}`.
Action: `{type:'take',gems:{white:1,...}}`, `{type:'buy',cardId,payment?}`, `{type:'reserve',cardId}` or `{type:'reserve',level}`, `{type:'discard',gems}`, `{type:'noble',nobleId}`, `{type:'pass'}` only if no normal move. Pending: null or `{type:'discard',count}` or `{type:'noble',nobleIds:[]}`. `legalActions` returns actual executable JSON actions; pending discard can enumerate a bounded useful selection, validation accepts every legal combination. View strips decks to counts and other players' reserved cards to `{id:'hidden',level}`. `applyAction` returns a new game; logs `{playerId,text}`.
